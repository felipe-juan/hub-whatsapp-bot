HUB WhatsApp Bot v0.15.9

1. Leia README.md.
2. Copie .env.example para .env e configure a senha local.
3. Execute: npm ci --ignore-scripts --no-audit --no-fund --legacy-peer-deps
4. Execute: npm run check
5. Inicie: npm start

Atualização simplificada:
